# Native SVG source notices

The `upstream_path` fields preserve locations in the original source-adoption
snapshot. Unmodified crates subsequently restored to the registry no longer have
those local vendor paths. Their copied license bodies and fixed membership hashes
remain unchanged; current dependency sources and archive checksums are recorded in
the active Cargo locks and `FORKS.md`.

The bounded SVG source module preserves the accepted resvg/usvg 0.49.0 engine and its fixed dependency versions. Each third-party tree retains its original copyright and license text. `dependency-notices.json` binds these notices to their actual vendored files. Notepads modifications do not replace upstream terms with the repository MIT license.

This inventory covers source adoption. It grants no UWP, Native AOT, rendering-quality, or formal SVG product qualification. The current Markdown control still reports SVG as Unsupported. The original source probes and their failures remain separate immutable evidence. Normal/build dependency license expressions are recorded in `artifacts/evidence/r12/svg-product-integration-v1/owned-job-implementation-v1/SVG-DEPENDENCY-LICENSE-TREE-V1.txt`.

Their complete original license files, crate checksums and upstream revisions are bound by the inventory.
